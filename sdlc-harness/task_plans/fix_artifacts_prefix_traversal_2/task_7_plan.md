**Depends on:** Tasks 1–6. This catch-all task documents what they built, so it ships after them. The behaviour it documents:
- **`artifacts_prefix`** (`src/scenewise/app/delivery.py`, Task 1) compares the requested `uri_prefix` with the state prefix after normalising both: scheme and host lowercased, `file://localhost` read as `file://`, percent-escapes decoded, leading or repeated slashes collapsed, dot segments removed (`posixpath.normpath`). It refuses a prefix equal to or under the state prefix. It also refuses a prefix with a query, a fragment or a relative path. Each refusal is `InputError(code="uri_not_allowed")`, which ends the job `failed`. An accepted prefix keeps the caller's spelling, with `/{job_id}` appended.
- **`LocalBlobStore`** (`src/scenewise/adapters/storage/local.py`, Task 2) takes `fenced: Sequence[Path] = ()`. A path that resolves into a fenced root must also be spelt inside it, or the store raises `uri_not_allowed`.
- **`bootstrap._stores`** (Task 3) builds the output store as `LocalBlobStore(roots=[state path, *artifact_roots], fenced=(state path,))`. That refuses a symlink in an artifact root that points into the state directory, and a second spelling of a parent directory.
- **`tests/e2e/test_isolation.py`** (Task 6), in `test_cross_job_overwrite_is_refused`, asserts `failed` / `uri_not_allowed` for every spelling and that the attacker has nothing under the state prefix except its own record. `test_a_symlink_into_the_state_prefix_is_refused` covers the symlink case.
- **Remaining limit:** the comparison is case-sensitive. On a case-insensitive filesystem (macOS default) with an artifact root that **contains** the state directory, a case-changed spelling such as `…/STATE/victim` is not caught. The local store is a single-host development and self-hosting store, with Linux as the deployment target (D14).
