### Task 1 — Compare the normalised artifact `uri_prefix` with the normalised state prefix in `artifacts_prefix`

**Goal:** Make `artifacts_prefix` refuse any requested `uri_prefix` whose **job folder** — the folder the artifacts actually go to, `{uri_prefix}/{job_id}` — **normalises** to the state prefix or a path under it. That covers a prefix that is itself at or under the state prefix, spelt with `..`, `.`, repeated slashes, a leading `//`, percent-escaped dots or slashes, an upper-case scheme, or the `localhost` host for `file`. It also covers a prefix **one level above** the state directory combined with a job id equal to the state directory's basename: `file:///srv` with job id `state` against state `file:///srv/state` would otherwise write `file:///srv/state/a1/…`, into job `a1`'s record folder. Also refuse the three spellings that would make the checked string and the written path disagree: a query, a fragment (a `?` or `#` anywhere in the prefix, an empty one included), and a relative path. Each refusal is `InputError(code="uri_not_allowed")`. The work is pure stdlib string processing, so `app` takes on no adapter or filesystem concern (`.claude/context/conventions.md` § Dependency direction: `app` imports only the stdlib, `pydantic`, `pydantic_core` and `structlog`).

**Where this layer stops.** This task does no filesystem work: no `Path.resolve()`, no `os.path.realpath`, and no symlink handling. Symlinks and alternative spellings of a parent directory (for example `/private/var/…` for `/var/…`) are invisible at the URI level. They are refused by the output store's new `fenced` roots, which **Task 2** builds (`LocalBlobStore(…, fenced=…)`) and **Task 3** wires (`fenced=(state path,)` in `bootstrap._stores`). This task does not import or mention either. The unit tests for this task are **Task 4's** (`tests/unit/test_delivery.py`), because `tests` is its own layer. This task edits no test file.

**`job_prefix` and `record_uri` are deliberately unchanged, but one safe segment does not make every composition safe.** Every caller passes a `JobId` built by `scenewise.domain.jobs.job_id`, and `JOB_ID_PATTERN` (`^[A-Za-z0-9._:-]{1,200}$`, with `.` and `..` refused) keeps the id one segment that can neither climb (`..`) nor smuggle a separator or a percent-escape. That is what keeps `record_uri(state_prefix, job)` and the default `job_prefix(state_prefix, job)` inside their own folder under the configured state prefix. It does **not** stop a single segment appended to an **ancestor** of the state directory from landing exactly on it (`file:///srv` + `state`), which is why the containment check in Work bullet 2 runs on the composed job folder, not on the requested prefix alone. Do not retype their `job: str` parameter: the existing tests call them with plain strings (`tests/unit/test_delivery.py` `job_prefix("mem://state/", "j")`).

### Targets

- `src/scenewise/app/delivery.py`: `artifacts_prefix`, plus one new private helper beside it.

**Source:** `src/scenewise/app/delivery.py` (`artifacts_prefix`, current lines 114–128). The current check is `requested == state or requested.startswith(f"{state}/")` on the `rstrip("/")`-ed raw strings.

**Work:**

- [ ] Add a private helper `_location(uri: str) -> tuple[str, str, PurePosixPath]`, returning `(scheme, host, path)` for comparison only. It must never raise. Build it from `urllib.parse.urlsplit`, `urllib.parse.unquote`, `posixpath.normpath` and `pathlib.PurePosixPath`, all stdlib:
  - `scheme` is `parts.scheme` (`urlsplit` already lowercases it).
  - `host` is `parts.netloc.lower()`, except that a `file` URI whose host is `localhost` gets `""` (RFC 8089 §2: the two are the same location, and `LocalBlobStore._path` accepts both).
  - `path` is `unquote(parts.path)`, with an empty path read as `"/"`. Collapse a leading run of slashes to one (`"/" + p.lstrip("/")`, because `posixpath.normpath` keeps exactly two leading slashes), apply `posixpath.normpath`, and wrap the result in `PurePosixPath`.
  - The docstring states that this is URI-level only and follows no symlink.
- [ ] Reorder `artifacts_prefix` for a requested prefix (`job.artifacts_prefix is not None`) so the refusals run first:
  - (a) the raw string contains a `?` or a `#` anywhere (`"?" in requested or "#" in requested`): raise `InputError(code="uri_not_allowed", detail="artifacts uri_prefix may not carry a query or fragment")`. Test the raw string, **not** `urlsplit(requested).query` / `.fragment`: `urlsplit` returns `""` for an empty `?` or `#`, so `file:///srv/artifacts/shared?` and `file:///srv/artifacts/shared#` would get through, and `LocalBlobStore._path` (which reads only `parts.path`) would put every job's `…?/{job_id}/a1/audio.wav` and `…?/{job_id}/a1/result.json` on the one path `/srv/artifacts/shared`. The appended `/{job_id}/a{n}/…` would otherwise land in the query or fragment, and every job would write the same file.
  - (b) its unquoted path is non-empty and does not start with `/`: raise `InputError(code="uri_not_allowed", detail="artifacts uri_prefix must have an absolute path")`. A `file:state/victim` path resolves against the process's working directory.
  - (c) normalise the **job folder** `folder = job_prefix(requested.rstrip("/"), job.id)` (the exact string this function returns) through `_location`. When its `scheme` and `host` equal the state location's and its path `is_relative_to` the state path (this covers equality), raise the existing `InputError(code="uri_not_allowed", detail="artifacts may not be written under the state prefix")`. Checking the folder subsumes checking the requested prefix: a prefix at or under the state path yields a folder under it, because the appended id is never `.` or `..`. It additionally catches `file:///srv` + job id `state` (folder `/srv/state`, equal to the state path) and `file:///srv/artifacts/..` + `state`. The same parent prefix with any other job id (`file:///srv` + `other` → `/srv/other`) is **not** refused here; whether `/srv` is writable at all is the output store's allow-list decision.
  - Normalise `state_prefix` through the same `_location`. It is operator configuration (`ServiceSettings.state_prefix`, absolute by default via `_default_state_prefix`), so the refusals in (a) and (b) are applied to the requested prefix only.
  - No `detail` may interpolate the URI (D8, `.claude/context/conventions.md` § Logging).
- [ ] Keep the return value exactly as today: `job_prefix(job.artifacts_prefix.rstrip("/"), job.id)` (the `folder` computed in (c)), the caller's own spelling with the job id appended. The check is on the normalised form only, so `result_uri` for every accepted prefix is byte-identical to today's. Keep the `job.artifacts_prefix is None` branch (`job_prefix(state_prefix, job.id)`) unchanged.
- [ ] Rewrite the `artifacts_prefix` docstring:
  - The job folder `{uri_prefix}/{job_id}` — not just the requested prefix — is compared with the state prefix after both are normalised (scheme and host case, `localhost`, percent-escapes, dot segments, repeated slashes), so a parent of the state directory plus a job id equal to its basename is refused too.
  - Queries, fragments and relative paths are refused.
  - Symlinks are the output store's concern.
  - Stay within `.claude/context/conventions.md` § Code shape: `Final` for any new module constant, keyword-only where options are added, no explicit `Any`, no `noqa`. Stay within the complexity limits (≤ 8 cyclomatic, ≤ 6 returns, ≤ 10 branches). Move the refusal checks into the helper or a second private helper if `artifacts_prefix` would exceed them.

**Deviations from plan:**

- `urlsplit` raises `ValueError` on some inputs (e.g. `file://[/srv`, an unclosed IPv6 bracket), so two branches were added that the plan did not list. (1) `_shape_refusal` refuses a requested prefix that `urlsplit` cannot parse: `InputError(code="uri_not_allowed", detail="artifacts uri_prefix is not a valid URI")`. (2) `_location` returns `("", "", PurePosixPath("/"))` instead of raising, which is what the plan's "must never raise" requires. That case only comes up when `state_prefix` is misconfigured, and it fails closed: a scheme-less absolute prefix is then refused. Task 4 needs a case for each branch to keep `app` at 100% branch coverage. The refusal checks were moved into a second private helper, `_shape_refusal`, as the complexity bullet allows.
